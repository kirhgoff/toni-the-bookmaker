## UI principles

- Keep the main flow obvious: choose a model/voice, add the book, select a render host, start, track, download.
- Prefer clear labels, keyboard-accessible controls, visible focus states, useful empty/loading/error states and responsive layouts.
- Use real audio controls for previews; indicate when a model needs a user-provided sample and do not imply unsupported voice customization.
- Keep advanced tuning secondary. Show render state and recent progress without requiring a manual refresh.
- Avoid unnecessary animation, decorative complexity and external services for core functionality.
